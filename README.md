# Hunt-the-Wumpus-

This is my Hunt the Wumpus project from my CS162 class. This program runs a grid-based “Hunt the Wumpus” style adventure where the player explores a cave filled with hazards, treasure, and events. It builds a randomized cave layout, places unique event objects like the Wumpus, pits, bats, treasure, and arrows, then tracks the player’s movement and interactions in real time. As the player moves, the game displays percepts from nearby hazards, handles encounters, and allows actions like shooting arrows to defeat the Wumpus. The game ends when the player wins by escaping with the treasure or loses by triggering a fatal event.

Run in a unix terminal running main.py to play the game.
